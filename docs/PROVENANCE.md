# 出处与致谢（Provenance）

## 1. 代码血统

本仓库的代码由本项目编写：全新历史、独立标识、独立签名；依赖是公开许可的第三方库
（见 `THIRD_PARTY_NOTICES.md`），依赖树内的二进制均为公开许可发行物。

产品概念「先完成学习任务，再使用设备的娱乐时间」参考了上游项目 **StudyOnTV**（作者 chadyi，许可
Source Available — Personal Use Only），在此致谢。本项目与它是独立实现，按代码血统计算各自成立。
此前一份基于该上游的 fork 已停止分发，仅作个人自用留存。本仓库现阶段同样保持私域（D29），
不向第三方分发。

## 2. 种子题库的编写位置

自创种子题库（`packs/starter-cc0/`）的编写源目前位于旧 fork 仓库——那边已有题库数据源与生成脚本。
旧仓库在本项目中的角色限定为 CC0 内容的编写位置：本产物按自己的提交记录发布，迁移是单向复制，
复制完成后与源仓脱钩。旧仓库若重新公开分发，D19 切换为独立源仓 `youban-packs`。

## 3. 沿用的内容范围

沿用下来的是行为事实与实测结论，每条都由真机复核：Android 7 上某姿态库的 `.so` 缺 API 26 的 locale
符号导致 `dlopen` 失败；厂商固件在重启时清掉悬浮窗授权；开机自启的可靠通道是厂商白名单里的「启用应用」；
国内镜像的产物路径走 blob 形式且有分钟级索引延迟；Gradle Sync 会清理目标目录中非自身产出的文件；
老库升级路径在全新装机上测不出来；75 寸 / 3 米观看距离下正文低于 20f 读不动；电视形态基本收不到通知。
全部以本项目自己的表述记录在 `facts/DEVICES.md`。

源码、类名与函数名、界面布局与文案、构建产物与二进制由本项目独立编写。

## 4. 开发期引用的第三方技能

开发机上装了一把外部技能作产品判据：`mblode/agent-skills` 的 `product-design`（MIT，来源版本
`4687e4b3966d83f0abea2df9720d8349b436ba56`，作者 Matthew Blode）。它只是**判据**——动作的对象·范围·后果·
可逆性，枚举可达状态，离线与过期算设计态——用来在 M4 之前把页面清单与「周报」那两条过一遍。
**它不进仓库、不进 APK、不参与任何判定**；本仓库的规范仍然只有 `spec/`、`contract/`、`model/` 那三处。
署名随技能目录留存（`~/.agents/skills/product-design/LICENSE.md`）。

## 5. 重写的两条动因

1. **许可**：上游许可限制衍生作品的再分发，此前那份 fork 曾公开分发源码与二进制。许可按代码血统判定，
   与名称无关。
2. **设计**：结论可解释、可发动议（旧称「可申诉」）、按协议交出编辑权、执行方式作为可选例外。落点在
   [`LAYERING.md`](LAYERING.md)（按层给能力）与 [`../spec/AUTONOMY.md`](../spec/AUTONOMY.md)（六条规则）。

## 7. K12 内容的来源（第三方包，D82）

编写源是别人的仓：`cn-math-taxonomy`（<https://github.com/xiaoyang111222/cn-math-taxonomy>），
许可 **CC BY-NC 4.0**，其中「商业使用需单独授权」的声明随署名一并保留。取法与 §2 那条「旧 fork 当草稿纸」
**不一样**，要分清：

- §2 那一节说的是**本项目自创**的 CC0 种子题——编写位置在旧 fork，产物是 CC0。
- 这一节说的是**第三方内容**——它不是 CC0，装进这台设备靠的是 `contract.contentPack.license.conditional`
  那唯一一条条件条目：只在 `distribution = private` 时可装，跟着 D29/D30（不公开发布、不收费）走。
  那三条撤销条件任一发生，包按 `PACK-04` 卸干净。
- 取的是义务教育段（点 2591、边 3663、题 10129；裁掉点 707、边 1205），**高中段一题不绑**（D76）。
- **人工核对做过一次**（`PACK-08` 要求的就是这一步）：题面里 40 字以上的引文只有 2 处，且都是自造的句子；
  没看到整段教材原文照抄的痕迹。真正发现的问题不是版权而是**可用性**——题面或解析里出现
  「课文 / 原文 / 教材」的有 382 道，这类题预设「手上有那一本教材」，而这台设备不知道孩子用的是哪一版课本；
  这一类在导出时滤掉、门再验一遍（`contentPack.textbookDependent`）。
- 一处**已知没滤的**：语文题里有 358 道在题面里引用《…》——名著与课文混在里面，一刀切会把名著题一起砍掉，
  所以留着并在这一点上如实标着：这类题可能需要孩子手边有那一本书。

## 界面字体与构建取件（2026-11-10）

- 界面字体：**当前 APK 不随包带任何字体**（试过 Noto Sans SC 子集与 DroidSansFallback 子集各一次，
  都没在设备上验成，已回退，`facts/DEVICES.md#F17`）。原因是设备本来就有 CJK 字体
  （`NotoSansCJK-Regular.ttc` 等），随包带字体这条路的授权成本本来不必要——
  等确定设备自带字体不能用时再谈带字体，届时 OFL/Apache 全文必须一起进包。
  今晚顺手记下：`scripts.sil.org` 403、`raw.githubusercontent` 上那两条路径 404，取全文要换源。
- 构建取件走镜像：`mirrors.cloud.tencent.com/AndroidSDK/`（build-tools 34.0.0、platform-33_r01），
  约 1.5 MB/s；同一批文件走 `dl.google.com` 今晚反复超时。**镜像包没有拿到权威校验值**，
  只做了 zip 完整性与内部结构核对（`aapt2`/`d8` 在位、`android.jar` 里有 `TIRAMISU`）。
  将来公开发布时，这些二进制必须换成有校验值的来源，或按 sha256 与官方 `repository2-*.xml` 对账。
