## 2. 定名规则对照

五条定名规则（D1）：

| 规则 | 有伴 |
|---|---|
| 桌面 label 2–4 字，大字号读得清 | 两字 ✓ |
| 口述传播不歧义 | `yǒubàn` 无常用同音词（不像「伴视」=「办事」、「看伴」=「砍半」、「视伴」=「事变」）✓ |
| 不宣称做不到的功能、不碰敏感词 | 名称不含护眼 / 防沉迷 / 管家 / 银行 ✓ |
| 检索区隔 | 名称与包名不含「电视」二字，与在俗 IPTV 项目分区；副标题承担检索词 ✓ |
| 名字与实现一致 | 「有伴」指设备承担计数与解释的分工；数据留在本机（`PRIVACY.md`）✓ |

## 5. 界面用词（全员一致）

实现与文案只用下表用词；括号里的旧叫法只出现在 `GATE.md` 的别名表与历史记录里。

| 界面用词 | 字段 / 枚举 | 一句话定义 |
|---|---|---|
| 成员 | `member:<id>` | 家庭里的一个人；契约里人人同一主体，无特权身份（D33） |
| 模式 | `profile` + `PROFILE_SWITCH` | 电视端区分人的那一层切换；一台设备一次一个人（D35） |
| 规则编辑权 | `roles: ruleEditor` | 约定字段的编辑权；可委托、可轮值、可收回 |
| 监护人凭据 | `roles: keyHolder` | 出网开关与数据保留天数的持有人；移交需本机当场确认（`AUTO-09`） |
| 动议（旧：申诉） | `MOTION` | 一条待对方受理的临时变更请求；未受理不生效（D34） |
| 受理 / 婉拒 | `MOTION_SETTLED(accepted)` | 对方在自己界面里的一次回答；都附一句理由 |
| 受托方 | — | 接受了约定字段编辑权委托的那位成员 |
| 轮值 | `ROLE_CHANGE` | 角色按协议交接，留痕、可收回 |
| 家庭面板（旧：家长面板） | `panel/` | 浏览器里的同一份账与规则视图 |
