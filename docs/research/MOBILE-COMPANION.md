# 手机端与陪伴端：证据整理

手机端从「配套管控端 + 体感端」改为**独立的陪伴端**。这一页整理这个改动的证据基础，
与 [`EVIDENCE.md`](EVIDENCE.md) 同一套判读规则（A 元分析/系统综述/RCT，B 纵向，C 横断，D 理论）。
**核对状态**：书目元数据已核对；标「读全文」的条目在实现前需完成全文核对。PMID 均可在 PubMed 直接验证。

## 1. 手机使用与福祉：基线别夸大

| 证据 | 结论 | 等级 |
|---|---|---|
| Sohn et al., 2019, *BMC Psychiatry*, PMID 31779637 | 问题性手机使用的患病率与心理健康结局的合并关联，横断证据为主 | A/C |
| Yang et al., 2020, *Psychiatry Research*, PMID 31757638 | 问题性使用与睡眠、抑郁、焦虑的关联（横断合并） | A/C |
| Paterna et al., 2024, *J Behav Addict*, PMID 38669081 | 问题性手机使用与学业成就的元分析：关联为负但异质性高 | A |
| 成人「手机使用时长」与福祉的因果证据 | 缺少；本项目的界面与文案不使用时长因果话术 | — |

**落到设计**：手机端没有「使用时长上限」这一功能，也没有阻断。可支持的干预点是**打断久坐、促成人与人的接触**（§2、§3）。

## 2. 提示的时机与内容：手机端唯一有强证据的能力

| 证据 | 结论 | 对设计的支持 |
|---|---|---|
| Nahum-Shani et al., 2018, *Annals of Behavioral Medicine*, PMID 27663578 | JITAI 设计原则：在**易受影响的时刻**给**适配当前状态**的支持，且要定义触发规则与更新规则 | `presence` 三档与 `due.window` 的定义方式 |
| Leppe-Zamora et al., 2025, *IJBNPA*, PMID 40514667 | 电脑提示打断久坐的元分析：能减少坐位时间，效果量中小 | 久坐打断与「一起动 2 分钟」的邀请 |
| Murtagh et al., 2020, *Cochrane Database Syst Rev*, PMID 32678471 | 工作场所以外的久坐干预：部分成分有效，整体证据不稳 | 邀请频率上限；不承诺效果 |
| Feter et al., 2019, *Int J Public Health*, PMID 30758514 | 手机促进体力活动的系统综述：有效但依从衰减明显 | 陪伴端的行为要落在**身体动作**上，不落在通知上 |
| Chen et al., 2026, *BMJ Open*, PMID 41991260 | eHealth 久坐中断 vs 体力活动促进的对照：两类都有效应，机制不同 | `exerciseTask` 与 `quizTask` 各自独立入账 |
| Murnane et al., 2020, *CHI*, PMID 33880463 | 环境式叙事界面用于身体活动的反思与激励：可接受性优于图表式反馈 | 状态条与周报的呈现形式 |

## 3. 促成人与人的接触：陪伴端的正题

| 证据 | 结论 | 对设计的支持 |
|---|---|---|
| Noone et al., 2020, *Cochrane Database Syst Rev*, PMID 32441330 | 视频通话减少老人的社会隔离与孤独：有正向证据，但研究少、质量中低 | 共看安排与「一起看」的信令设计 |
| Hoang et al., 2022, *JAMA Network Open*, PMID 36251294 | 老人孤独/隔离干预的伞形综述：社会活动类与多学科类证据最强 | 陪伴端指向**共同活动**，而非人机互动 |
| Shekelle et al., 2024, *J Gen Intern Med*, PMID 38200279 | 社区老人孤独干预的系统综述：有效类别集中在增强社会连接 | 同上 |
| Shah et al., 2021, *JMIR*, PMID 34085942 | 数字技术干预降低孤独：部分有效，整体证据质量低 | 「数字陪伴替代人际」列为无依据（见 §5） |
| Chen & Schulz, 2016, *JMIR*, PMID 26822073 | ICT 干预与老人社会隔离：效应依赖使用障碍的排除 | 适老化与一步可达的入口 |
| Phang et al., 2023, *JMIR Aging*, PMID 36598801 | 代际数字项目的 RCT：与孤独、隔离的关联改善 | 家庭内异步互动（家长的话、共看邀请） |

## 4. 体感与姿态：能做到什么，不能声称什么

| 证据 | 结论 | 对设计的支持 |
|---|---|---|
| Donath et al., 2016, *Sports Medicine*, PMID 26886474 | Exergaming 对比其他运动：对平衡/力量有中等效应，与训练组相当 | 体感运动作为运动段的实现方式之一 |
| Di Lorito et al., 2021, *J Sport Health Sci*, PMID 32525097 | 老人运动干预的元分析汇总：运动对功能与情绪有效 | 老人的运动项目内容（平衡、坐姿操） |
| Liang et al., 2024, *J Frailty Aging*, PMID 39574284 | 居家力量 + 太极「运动点心」在 frail 老人中的可行性与效果 | 手机端短时长、高频次的运动邀请 |
| Laver et al., 2025, *Cochrane Database Syst Rev*, PMID 40537150 | VR 用于卒中康复：部分结局有益，证据质量不一 | 不宣称康复或治疗效果 |
| Ripic et al., 2023, *J Biomech*, PMID 37216895；Seuthe et al., 2025, *J Biomech*, PMID 41075586 | 无标记动作捕捉的有效性验证：步态与关节角度在临床量级仍有系统偏差 | **姿态只用于计次与节律**，不用于临床/健康结论（`SENSE-03`） |
| Eitivipart et al., 2018, *Hong Kong Physiother J*, PMID 30930581 | 手机使用与肌骨不适的系统综述：关联存在，异质性大、质量低 | 话术是「换个姿势」，不承诺矫正或治疗 |
| 待核 | 无标记姿态计数在老人、低光照、远距离下的可用性与误计率（对照人工计数） | F13（待实测） |

## 5. 明确列为「无证据支撑，因此不做」

1. 用使用时长限制来改善成人福祉（§1）。
2. 用数字陪伴替代家庭人际接触（§3 Shah et al.、Shekelle et al.）。
3. 用姿态识别给出姿态/健康诊断或矫正结论（§4 两条验证研究）。
4. 「低头族损伤」类的健康承诺（§4 Eitivipart）。
5. 以孤独作为面向使用者的指标（[`EVIDENCE.md` §5](EVIDENCE.md)、§7 同样结论）。
6. 高频通知作为陪伴手段（§2 Feter 的依从衰减、JITAI 的时机原则）。
