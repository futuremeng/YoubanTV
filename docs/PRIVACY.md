# 隐私与数据去向

这一页与「关于」页内容一致。原则：**未成年人设备上的数据默认停留在家里**；离开设备的路由 `keyHolder`
（监护人凭据持有者，`AUTO-10`）显式开启，
并在界面上写明目的地。

## 1. 每一项数据

| 数据 | 存放 | 出设备的条件 | 保留时长 |
|---|---|---|---|
| 题库（内容包 / 成员自编） | 本机 SQLite | 只在设备内 | 内容包随卸载移除；自编题由作者删除 |
| 知识点进度、间隔重复进度 | 本机 | 只在设备内 | 到本人清除为止（`AUTO-06`） |
| 答题记录、自评与修订结果、时长事件 | 本机 | 只在设备内 | 保留天数由 `keyHolder` 设置（与出网同属隐私域，`AUTO-10`），默认 400 天 |
| 前台状态 | 本机 | 只在设备内 | 取值为「当前内容是否受控」的布尔与时长（`AUTO-11`） |
| 前台窗口标题（伴看上下文） | 内存，一次一条 | 上下文已开启**且**启用 AI 出题时，作为题目上下文发往该 host | 内存内用完即弃；不进表、日志与界面（`CONTEXT-02/03`） |
| 手写答案图片 | 本机 | 把该题交给支持视觉的模型时（开关由 `keyHolder` 显式开启） | 可设为评完即删 |
| 摄像头帧与姿态关键点（运动计次） | 内存，逐帧丢弃 | 只在设备内 | 内存内即时处理；落盘的只有计次结果（`SENSE-02`） |
| 题干 + 答案 + 评分标准 | 内存 | 启用 AI 批后发往其填写的 host；开关由 `keyHolder` 显式开启（§6） | 内存内即时处理 |
| 设备待确认清单的状态 | 本机（派生视图，不落新账） | 只在设备内 | 条目由事件与探针证据推出；导出时列一节（`ONBOARD-10`） |
| 崩溃与诊断日志 | 本机环形缓冲 | `keyHolder` 点「导出 / 发送」，导出前显示全部内容 | 默认 7 天滚动 |
| 使用统计 | 本机（由事件表计算） | 只在设备内 | 随答题记录 |
| 配对信息（密钥句柄、scopes） | 本机 | 只在设备内 | 改密码或重启即失效 |

## 2. 出网目的地清单

主动联网只有这四处，CI 门要求新增出网调用先登记进本表（`.github/workflows/checks.yml`）：

1. `keyHolder` 配置的 AI 批 / 实时出题端点。启用伴看上下文时，题目上下文里含一条前台窗口标题；
   开启界面写明这一点（`CONTEXT-03`）。
2. 检查更新。现阶段私域（D29），清单与产物宿主只有本项目仓库的 Releases（`ARCHITECTURE.md §7`）。
3. 节假日数据同步。
4. `keyHolder` 显式操作的 Home Assistant 联动。

其余监听与请求都在局域网内。统计与遥测在设备本机完成。查阅与修订（`AUTO-15`）也只在局域网内，
不新增出网路径。

## 3. 前台信息与手机端权限

计时需要知道前台是否在被约定的内容上。取值范围：

- **需要**：当前内容是否受控（布尔）、持续时长。
- **可选**：开启伴看上下文后，当前前台窗口的一条标题，仅用于出题。
- 手机端请求的能力面：相机（可选、默认关）、通知（可选）、局域网发现。位置、通讯录、短信与通知读取
  在权限清单之外。
- 面板提供的是按时段的用量与约定状态；节目内容属于使用者自己的信息。

## 4. 每个人对自己数据的权利

| 权利 | 实现 | 留痕 |
|---|---|---|
| 看得到 | 与面板同一份账本视图 | — |
| 问得到 | 每次呈现都给出「哪条约定 + 差多少 + 下一步」 | `due_shown` 事件 |
| 说得上话 | 动议通道；受理与婉拒都附理由，未受理不生效（`AUTO-03`、`AUTO-16`） | `MOTION` / `MOTION_SETTLED` / `MOTION_UNANSWERED` |
| 删得掉 | `POST /api/me/purge` 清除自己的记录（家庭协议与他人的账本各自独立） | 一条审计事件 |
| 知道现状 | 「我的数据」页显示当前协商强度、当前层、伴看上下文开关状态 | 页面本身 |
| 拿得走 | 「导出我的数据」生成可读文件，经动议 `dataExport`（`AUTO-03`） | `MOTION` |

六项权利与 `AUTO-01..06` 一一对应；本项目不分配 `PRIV-*` 编号，引用隐私约束时写 `AUTO-11`、
`CONTEXT-02` 或本页的节号。

## 5. 调用的系统能力

| 能力 | 用途 | 取值范围 | 条目 |
|---|---|---|---|
| 使用情况访问 | 前台判定与时长 | 布尔 + 时长 | `AUTO-11` |
| 悬浮窗 | 角标、状态条、`ambient` 题浮层 | 角落区域，避让字幕区 | `LAYER-03` |
| 无障碍（可选） | 更快的前台判定 | 判定结果 | `LAYER-06` |
| 摄像头（可选，默认关） | 本机运动计次 | 内存内逐帧丢弃；预览分辨率上限与取景区域由用户设定 | D4、`SENSE-02` |
| 通知（可选） | 一次提示 | 每层都有应用内替代 | F2 |
| 媒体控制 | `focused` 任务期间请求播放器暂停 | 暂停 / 恢复请求 | F12 |

画面与声音的取值边界：图像与音频只在内存中逐帧处理，用途只有运动计次；出题依据的文本取值是
前台窗口的一条标题。设备所有者 / Kiosk / Lock Task、云端账号与跨家庭同步、应用卸载保护属于范围之外
（`PRODUCT.md §2`）。

## 6. 合规参考（非法律意见）

家庭场景下 14 岁以下儿童的信息按敏感个人信息处理：默认留在本机，外发一律由监护人显式开启（开关的
变更需当场再认证，D38），去向在界面上可见。自动上报这条路径在代码里不存在，新增它需要改代码并通过 CI。

两点成文声明：

1. **许可证不豁免监管**。Apache-2.0 只解决代码能否被使用、修改与再分发；合规义务与是否开源无关，
   反而因源码可复现而更易被逐条比对。本节的约束在开源后仍全部成立（`DECISIONS.md` 的 P4）。
2. **本应用不替代监护人**。它把约定讲清楚并记账；法定监护责任不随角色的轮值（`AUTO-09`）而转移。
   全体成员主体相同、权力靠协议授予（`AUTO-10`），**唯独出网开关这一个不对称保留**，
   它是法定监护人同意的要求，不是产品理念。
