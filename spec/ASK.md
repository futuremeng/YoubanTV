# ASK —— 选题管线与知识点

选题只回答一件事：**此刻该给这个身份出哪道题**。它不判断该不该出题，
也不判断能不能看（这个概念已删除）。输入是**身份的内容绑定 + 知识大纲 + 履约与答题历史**，
可选加一条伴看上下文（`CONTEXT-04`：上下文缺失时按大纲出题）。

### ASK-01 取材顺序与回落
`内容包绑定 → 成员自编 → 实时智能体`。每层落空即落到下一层，并在面板标注「本题来自实时生成，未校验」；三层都落空时按大纲随机出题。
取材范围只来自该身份的内容绑定。

### ASK-02 范围由内容绑定给出
`outlineScope.subjects/levels` 决定选题范围；越界的题**不出现**，也不提示「这题不在你选的范围内」
。范围切换要留 `PLAN_CHANGE` 记录。

### ASK-03 知识点状态机
词表与 `PRODUCT.md §5` 同一套：`unseen`（新接触）→ `learning`（学习中）→ `shaky`（需巩固）/ `weak`（薄弱）/ `mastered`（已掌握）。
迁移规则：同点连对 3 题入 `mastered`（包内不足 3 题时答对全部即掌握）；答错先出 1 道 `basic` 确认题，
确认题对 → `shaky`，确认题错 → `weak` 并沿硬先修向下找。由 `outline_edges` 的前置关系与 SRS 进度共同驱动。
状态迁移只由答题事件触发，不由时间或由他人手工设定（`ruleEditor` 可改但留 `PLAN_CHANGE` 记录，本人端可见）。
前置未掌握的知识点**不阻塞**出后续题（不设边界），但面板要显示依赖关系。

### ASK-04 难度阶梯
- 错 1 次降 1 星；错 2 次降 2 星；连对 3 次升 1 星；星级只影响**下一次选题**，不追溯已出的题。
- 有效题组直接沿用当日生效组数（`DAY-05` 那一处算法），选题器不再算第二遍。
- 补一补池：答错的题进池，按大纲相关度优先出；池容量 20 道，达到容量后最旧的题出池。
- 是否「先补完再开始新任务」由该身份自己设定（自管字段，`AUTO-14`）；其他成员只能提动议（`AUTO-03`），无强制开关。

### ASK-05 去重与冷却
- 冷却：默认 3 天 / 答错 ≥3 次延长至 30 天 / **主动放弃直接置 180 天**。
- 同日同知识点默认 1 道，例外只有「确认题」（上一道答错后同知识点再来一道，且同一次任务内最多一次）；
  因此同一知识点在一个任务内最多出现 2 题（1 道 + 1 道确认题，与 `PRODUCT.md §5` 一致）。
- 冷却的用途是避免重复；冷却中的题按冷却期出池。

### ASK-06 两种参与形式对题目形状的硬要求
`ambient` 题必须：题干 ≤30 字、每选项 ≤2 行、单键可答、预估 ≤5 秒，且属于**预测 / 观察 / 判断**三类；
`focused` 题不限，但必须能在一次浮层会话内完成。内容包未声明 `supports` 的题按 `focused` 处理。
authoring 门禁把这条做成校验：不满足就**不能**被标成 ambient。

### ASK-07 时机与选题独立
呈现时机由 `COMMIT` 与 `CONTEXT-06` 决定（`onDemand` / `timed` / 实验性 `atPausePoint`）。
选题管线**不得**为了凑时机提前出题或压着不出；每次实际呈现写 `due_shown`。
每次任务题目数有上限（默认 ≤8），该上限属自管字段，由该身份自己调（`AUTO-14`），超出即本次结束。

### ASK-08 实时生成的题必须过机检
智能体生成的题带可机检 `verify`（求值语义见 `ARCHITECTURE §7`）；不过则**不出、不入库**，
写 `llm_generate_failed`。落盘进草稿区必须带来源（模型、时间、提示词来源、是否采纳）。

### ASK-09 同一道题对所有身份是同一道题
`audience` 只决定**从哪些包里取**与默认字号令牌，不改变题意与 `verify`。同一知识点出现在 child 与
senior 包里时，进度与冷却**各自独立**（各自内容的绑定），但知识点 id 与大纲语义共享，跨身份掌握视图可叠加。

### ASK-10 出题的取材边界
- 上下文只作为提示词素材（`CONTEXT-03`）；不得因上下文而跳出该身份绑定的大纲范围。
- 题目里不得出现从其它身份、其它人数据里取的内容；不得出现应用名清单或截图类描述。
- 取材按内容包的 `audience` 过滤，与身份绑定取交集（`PROFILE-02`）。
- **内容包那一层是真的**（`D84`）：包在、验过、绑定年级里还有没答过的题——三者齐了才算取到；
  取题那一处与验包那一处是同一个 `model/pack.rb`（判定不写两遍，否则会出现「门绿着而模型取到没验过的题」）。
  `ANSWER` 那条因此带 `questionId`：没有这一格，「答过的不再出」根本没法判。池空就是这一层落空——
  按上面的顺序往下走一层，不在内容包那一层编一道题。
