# ONBOARD —— 设备待确认清单

一台设备一份清单，随成员与设备的加入增量扩充。它只回答一件事：**这台设备上还有什么没确认，
由谁在哪一处确认，没确认时按什么保守档落**。清单不是第二本账，也不是闸门。

### ONBOARD-01 清单是派生视图
`GET /api/checklist` 从事件、`capability` 登记表与 `roles` 现值算出条目与状态；清单本身不落新账，
没有「清单项」表。同一份数据供设备端与家庭面板两处显示（`AUTO-02`）。
- 状态取值：`pending`（待确认）/ `done`（已有完成证据）/ `unknown`（探测不到）/ `notApplicable`（本机不适用）。
- 每条带 `owner`（该由哪个成员那侧做）、`where`（在哪个界面做）、`evidence`（完成证据指向哪个事件或探针）。

### ONBOARD-02 装配决定固定项
`tv` 与 `mobile` 两份固定项清单（`ONBOARDING.md §2`、`§3`）。装配差异**只**出现在条目集合上：
判定、规则、功能集合对所有装配与所有成员相同（`PROFILE-02`）。固定项之外没有第三种来源。

### ONBOARD-03 随加入增量扩充
新增条目只能由 `ONBOARDING.md §4` 的触发事件产生：成员加入、设备加入、角色移交、身份删除、
内容包加入、出网目的地新增、系统更新或重启、系统时间被改、摄像头通道开启。扩充规则封闭，
**界面与代码都不得凭空生成条目**；新增触发需先写进那张表。

### ONBOARD-04 每条都有 owner 与 where
`owner` 只能是：成员、角色（`ruleEditor` / `keyHolder`）、或 `system`（后台探针自动完成的条目，
没有人需要勾选，状态只由证据推出）。`where` 只能是该成员自己的界面（他的模式、他的设备、或他打开的
面板页）。不存在「替别人勾掉」的路径：需要对方确认的条目，受理只发生在对方那一侧（`PROFILE-10`、`AUTO-16`）。

### ONBOARD-05 不是闸门，也不是激励
清单不得阻断任何功能、不得改变 `status` 的判定、不得参与星与掌握进度的计算（`AUTO-13`）。
完成度只以「已确认 N / 共 M」一个分数呈现，无连击、无徽章、无签到、无红点提醒的递进催促；
提示只用 L1 一条提示与面板一页（`LAYER-09`）。把清单做成督促工具是反设计（`AUTO-05`）。

### ONBOARD-06 未完成只降级，且降级规则唯一
`unknown` 与 `pending` 的落档只有一条规则：**取该能力最保守的可用档**，并在界面写明原因。
具体取值：暂停响应未探到 → `ambient`（D36）；悬浮窗未授权 → L2 以内；伴看上下文未确认 → `off`；
摄像头未标定 → 加速度计节律 + 手动确认。降级不影响其它条目与已生效的约定。

### ONBOARD-07 授权或固件变化后自动重开
厂商固件可能在重启时静默清掉悬浮窗授权（事实 F1）；系统更新与媒体应用更新同样使旧探测证据失效。
`capability` 登记表的探针在每一次到前台（`onResume`）重跑，证据的 `probedAt` 早于最近一次重启或更新的条目
自动回到 `pending`，`unknown` 则保持 `unknown`。这类重开不写事件，也不发通知。
**`onBoot` 这一路不靠开机广播**：开机后的第一次到前台就是那一次重跑。装包清单里不许有 `BOOT_COMPLETED`，
也不许有后台常驻与前台服务——声明与实现是否一致由装包清单门逐条核对（契约 `devicePermissions`）。

### ONBOARD-08 出网类条目
出网开关（AI 批、AI 出题、伴看上下文、诊断导出、Home Assistant）的条目由 `keyHolder` 确认，
且**变更需当场再认证**（D38）；未确认时默认关（`PRIVACY.md §6`）。清单里这类条目显示三件事：
去向地址、发什么、关掉的方法；不显示任何示例数据。其它成员的清单只读，显示「由谁已确认」。

### ONBOARD-09 条目必须有客观完成条件
完成证据只能来自三处：事件（`PLAN_SIGNED` / `ROLE_CHANGE` / `MOTION_SETTLED`）、`capability` 登记表的
探测记录（含摄像头标定自检）、`roles` 与内容绑定的现值。**不设「我知道了」型条目**：
无法用这三处证明的事项不进清单，改放常驻说明页（`AUTO-05`）。

### ONBOARD-10 清单里只有状态
每个条目在存储里只落 `id`、`owner`、状态、`evidence` 指针与时刻；不落姓名之外的内容数据，
不落截图与日志。导出「我的数据」时清单状态以一节列出（`PRIVACY.md §1`）。清单不进那一页的账（`REPORT-02`），
也不作为对某个成员的评价依据。
