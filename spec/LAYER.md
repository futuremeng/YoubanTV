# LAYER —— 分层策略条目

条文全文见 [`../docs/LAYERING.md`](../docs/LAYERING.md)。这里是可测的断言。

### LAYER-01 层级定义唯一，L4 已退役
- `Tier ∈ {L0, L1, L1.5, L2, L3, L5}`；`L4` 是枚举里的空位。
- `Tier` 描述侵入度与呈现时机。
- 每项能力必须登记当前层；`Capability.tier` 是**唯一**的强度事实来源。

### LAYER-02 默认停在最软的够用层（分两条线）
- **状态层**（此刻无 `due`）：只有角标剩余与**待受理动议**（一条提示，可忽略）时为 L1；存在需要持续可见
  的状态（`overdue`、**已受理的暂停**）时为 **L1.5**。与协商强度无关。L4 是空位；L5 需配对后生效。
- **到期档**（此刻有 `due`）：落层 = min(`tierFor` 的形态首选层, 该强度的默认档)，见 `ARCHITECTURE.md §9`。
  强度默认档高于形态首选层时不再上抬：陪伴式的 L3 表现为**默认开启 L3 的应用外呈现通道**。
- 首启引导只请求达成当前层**必需**的最小权限集（悬浮窗 / 使用情况）；不得夹带任何额外授权。
  引导的内容就是本机固定项的前五项（暂定值，见 `DECISIONS.md` 的暂定取值；`ONBOARD-02/03`）。

### LAYER-03 升层必须显式
- 升层动作 = 一次点击 + 一句「这一层会做什么 / 代价 / 怎么退回」。
- 入口条件：一次点击 + 三句说明（做什么 / 代价 / 怎么退回）；`revertPath` 字段由 CI 检查。

### LAYER-04 每层可独立回退；回退与降级都不丢数据、且必须可见
- 退层保留题库、账本与任务进度，只撤销该层的呈现效果。
- 每次 L5 开关写一条审计事件；**能力被系统静默收回**（如重启清掉悬浮窗授权）时，除审计外
不得只写日志。

### LAYER-05 能力登记表与措辞绑定
- 强度相关文案只读 `Capability`；取不到值时报 `unknown`。
- 探针在后台线程；`ttl` 过期即重探；重启后重探一遍（事实 F1）。

### LAYER-06 强制力的取值范围
- L4 是空位（D23）。应用可被随时卸载，关于页写明这一点。
- 设备所有者、Kiosk、Lock Task、强制更新属于范围之外（`PRODUCT.md §2`）。
- 无障碍作为 L3 判定的可选加速器（D16），接口面只返回判定结果。
- 开机广播是 L3 的触发器。
- L5 能真正停止观看（断电 / 切源 / 断网），但必须家庭显式配对、界面写明「由外部设备执行」，
  不可达时该条**失效并显示**（`LAYER-11`）。
- CI 门 `COMMIT-10`：出现阻断类 API 即红。

### LAYER-07 协商强度决定层的天花板与默认档（与年龄无关）
规则：**强度定天花板，天花板内取到期项的默认档**（陪伴式 L3 / 协商式 L2 / 自管式 L1）；
无到期项时的状态层与强度无关（`LAYER-02`）。落层 = min(形态首选层, 默认档)。两个推论：强度默认档高于
形态首选层时不上抬，而转为默认开启 L3 的应用外呈现通道（陪伴式）；`focused` 请求暂停不得低于 L2——
自管式的 L1 低于该下限时该题按 `ambient` 呈现并写明原因（F12）。强度由该身份自己选。

**机型探测门槛（D36）**：`focused` 只在后台探针探到「请求播放器暂停」响应率 ≥95% 的机型上作为默认档；
探不到、未达标或本机不支持时一律按 `ambient` 落档并写明原因，探测结果登记在能力登记表并按机型回填
F12。**默认值不等实测**——实测只用来把默认档抬上去。
矩阵对所有身份同一张：
| 协商强度 | L0–L2 | L3 | ~~L4~~ | L5 |
|---|---|---|---|---|
| 陪伴式 | ✓ | ✓ 默认 | — 不存在 | 需配对 |
| 协商式（默认） | ✓ 默认 L2 | ✓ | — 不存在 | 需配对 |
| 自管式 | ✓ 默认 L1 | ⚠️ 需知情：界面写明「题目会**请求**暂停播放，答完恢复；这台设备若不支持则自动改为不打断模式」（F12） | — 不存在 | 需配对 |

- D13（自管强度与 L4 互斥）**因 L4 删除而自动成立**，条目退役；不要再把它实现成一段校验代码。

### LAYER-08 降级必须可见
- 不得只在日志里写。系统通知不可靠（F2），因此降级提示必须落在应用画面内。

### LAYER-09 措辞按层给
L0/L1 告知 / L1.5 状态句（「已暂停 <时长>，<时刻> 恢复」「今天还剩 <X>，已按约定使用」——
给出当前状态与恢复时刻） / L2 约定 + 该做的事 + 窗口期 / L3 浮层位于内容角落并避让字幕区 /
L4 是空位；L5 委托（「由外部设备执行，本机只发请求；外部设备不可达时这条失效」）。
`overdue` 的措辞是状态句：「超出约定 12 分钟」。

文案取值范围（CI 扫字符串常量）：状态句 + 下一步 + 常驻说明；鼓励语来源为任一家庭成员撰写的句子（标注到人）。
成就、连击、排行、签到、称号、推送、奖励弹窗、内部术语在取值范围之外（`AUTO-05`、`AUTO-13`）。

### LAYER-10 提示必须有应用内替代
每一层的提示都有应用内替代实现；系统通知作为其中一条通道（F2）。

### LAYER-11 外部协同不越权宣称
L5 由外部设备执行；本机只发请求。外部设备不可达时该条**失效并显示**，不得由本机冒充执行。

### LAYER-12 场景表是准入门
新增能力先在 `LAYERING.md §2` 的表里占一行（在哪层 / 默认层 / 上面还有哪层），再进代码。
